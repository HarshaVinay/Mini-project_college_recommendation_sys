# College Recommendation System

A college recommendation project that filters and recommends colleges based on a student's EAMCET rank and eligibility criteria.

## Overview

The application takes student inputs and uses rank-based filtering to identify colleges that match the provided eligibility conditions.

## Key features

- Student rank input
- College filtering based on eligibility
- Personalized college recommendations
- Simple recommendation flow

## Project goal

The goal is to make college discovery easier by reducing a large set of college options to a smaller list based on the student's rank and eligibility.
